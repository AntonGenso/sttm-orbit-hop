# ORBIT HOP — STTM

Однокнопочная орбитальная аркада для платформы Step to the Moon.
Ракета сама цепляется за орбиты планет; тап — отпускает её по касательной.
Собери звёзды и доберись до Луны с флагом Узбекистана. Стиль — бумажный коллаж.

**Запуск: `index.html`** (меню → game.html). Платформа встраивает игру через iframe
по адресу `index.html?nickname=ИМЯ` — язык и никнейм передаются в игру автоматически.

## Структура репозитория

```
index.html        — стартовый экран: PLAY, переключатель языков UZ/РУ/EN (ползунок)

menu-bg.webp      — фон стартового экрана
assets/           — 38 спрайтов игры (список ниже)
README.md
ORBIT_HOP_GDD.md  — дизайн-документ
```

## Очки и интеграция STTM

- Максимум очков: **100** (в полной карте: 20 звёзд × 5).
- `window.parent.postMessage({type:'SUBMIT_SCORE', score:N}, '*')` — накопительно:
  после каждой подобранной звезды, на финише и при гейм-овере.
- Никнейм: `?nickname=`, дефолт `Player`. Язык: `?lang=uz|ru|en`.
- Firebase SDK в игре не подключён — очки пишет платформа.

## Управление

Один тап (палец / клик мыши / пробел) — отпустить ракету с орбиты.
Крупная подсказка «ТАПНИ!» показывается на старте до первого тапа.

## Правила

- ❤️❤️❤️ — сердце теряется: от кометы, при вылете за экран и когда горячая планета поглощает ракету.
- Горячие орбиты: кольцо наливается красным ~5 с, потом планета втягивает ракету (−1 ❤️, возврат на ту же орбиту).
- Промах внутри экрана — буксир спасает бесплатно, цена — время.
- Разноцветные звёздочки-конфетти: при подборе звезды, уроне и поглощении.
- 0 сердец → «Ракета устала»: сабмит накопленных очков, кнопки ПЕРЕИГРАТЬ и МЕНЮ.

## Деплой

1. Залить все файлы в репозиторий (структура как выше).
2. Settings → Pages → ветка `main`, папка `/ (root)`.
3. URL для платформы: `https://antongenso.github.io/sttm-orbit-hop/index.html`
4. Проверять обновления с Ctrl+Shift+R (кэш Pages ~10 минут).
